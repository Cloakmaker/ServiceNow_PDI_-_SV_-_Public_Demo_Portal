# ServiceNow_PDI_-_SV_-_Public_Demo_Portal
This portal is a personal project challenging the skills I have learned in the development and administration of ServiceNow.

This portal is meant to be publicly accessible and provide information as to how I've accomplished various configurations and customizations. It is also meant to be an entry point for users to check out other applications I have or will eventually develop.

Please pay close attention to the fact this is a scoped application. There are several customizations including copies of widgets, events, notifications, mail scripts, etc. all because they are not entirely designed in a way that works in a scoped setting. The portal provides public access to a growing knowledge base which goes into these things in detail.
